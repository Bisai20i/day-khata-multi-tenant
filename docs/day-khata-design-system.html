The visual language for Day Khata

Every color, type size, and component the new Day Khata product will be built from — collected on one page so it can be reviewed and signed off before screens get built. Nothing here is a mockup of a specific page; it's the parts kit those pages will assemble from.

Accessibility. Every text/background pairing above has been checked against WCAG 2.1 AA (4.5:1 normal text, 3:1 large text). Text Muted is the floor for real body copy — Text Faint is reserved for placeholders and decorative use only. Danger on its tint is 3.95:1: fine for badges/icons/large text, not small running text.

Typography

One family — Inter — carrying the whole interface through weight and size rather than mixing typefaces. This is deliberate: an accounting product is read in dense, data-heavy screens, and one disciplined family stays legible longer than a decorative pairing would.

Shape & spacing

Every corner on this page is 0px. That's not unfinished styling — it's the one rule every component obeys without exception, the same way the color and type rules are obeyed. The single exception is a fully round avatar, which doesn't appear on this page because no avatar component exists yet.
